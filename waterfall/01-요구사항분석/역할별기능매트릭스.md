## 1. 역할

| 역할 | Actor ID | 하는 일 | 권한 | 인증 |
|------|----------|---------|------|------|
| 방문자 | ACT-01 | 공개 페이지 열람, RSS 주소 복사 | 열람 | 없음 (로그인 없음) |
| RSS 리더 | ACT-05 | 방문자 대신 피드를 주기적으로 읽음 | 열람 | 없음 |
| 운영자 | ACT-02 | 발행 작업 수동 실행, 실패 대응, 호 데이터 정정·삭제, 비밀 값 관리 | 저장소 쓰기 | GitHub 계정 |
| 스케줄러 | ACT-03 | 매일 발행 작업 실행과 배포 (GitHub Actions) | 저장소 쓰기, 배포 | 저장소 권한 |
| 외부 시스템 | ACT-04 (ACT-S01~S04) | 출처 4곳, Claude API, 위키백과 API, Cloudflare Pages | 해당 없음 | 각 서비스 규칙 |

계층형 권한은 없다. 방문자와 RSS 리더는 같은 공개 콘텐츠를 보고, 운영자는 스케줄러가 하는 일을 수동으로도 할 수 있다 (유스케이스 명세서 2.3).

## 3. 역할별 요약

| 역할 | 할 수 있는 일 | 할 수 없는 일 |
|------|---------------|---------------|
| 방문자 | 6개 페이지와 호별 페이지 열람, 지난 호 검색, 주제 필터, RSS 주소 복사 | 로그인, 댓글·좋아요, 개인화, 데이터 수정 |
| RSS 리더 | 최근 20개 호 피드 읽기 | 그 밖의 모든 일 |
| 운영자 | 발행 작업 수동 실행, 실패 대응, 호 정정·삭제, 비밀 값(API 키 등) 관리 | 관리자 화면 사용 (EX-005, 데이터 파일 직접 수정으로 대체) |
| 스케줄러 | 매일 발행 작업 실행, 호 커밋, 테스트·사이트 생성·배포 | 이미 발행된 호 수정 (정정은 운영자 몫) |
