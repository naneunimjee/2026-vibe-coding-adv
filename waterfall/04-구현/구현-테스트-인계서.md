## 2. 빌드와 테스트 환경

| 항목 | 기록 |
| --- | --- |
| 재현 가능한 빌드·실행 | Python 3.12 (Actions) / 로컬 3.14에서도 확인. `pip install -r requirements.txt` (jinja2 3.1.4, google-genai 3.6.1) → `python -m unittest discover -s tests` → `python build.py` |
| QA 환경·접근 | 운영 사이트 = Cloudflare Pages 프로젝트 `it-newsletter` (주소는 저장소 변수 `SITE_URL`). Actions 화면에서 "매일 발행" 수동 실행 |
| 환경 설정·기능 플래그 | Secrets: `GEMINI_API_KEY`, `CLOUDFLARE_API_TOKEN`(Pages 편집 권한), `CLOUDFLARE_ACCOUNT_ID`. Variables: `SITE_URL` (https). 셋 중 하나라도 없으면 배포 단계만 건너뜀 |
| 데이터·마이그레이션 | 첫 실행은 직전 호가 없으므로 최근 24시간 수집, 제1호로 저장. 잘못된 호는 파일을 고쳐 `main`에 푸시하면 재배포 (UC-009) |
| 외부 연동 | 단위 테스트는 네트워크·Gemini 없이 가짜 응답(fixtures, mock)만 씀. 실제 연동은 수동 실행 1회로 확인 |

접근 자격 증명은 GitHub Secrets에만 둡니다. 로컬 실행 시 환경 변수로만 넣고 `.env`는 커밋하지 않습니다.
